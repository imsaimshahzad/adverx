# AdverX

AdverX is a TanStack Start + React + TypeScript application backed by Supabase. The repository contains the web app, Supabase Edge Functions and migrations, and a separate Drizzle migration history.

## Quick start

1. Install Node.js (use a version supported by the current Vite/TanStack toolchain).
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env.local` and set `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` for your Supabase project.
4. Start the development server: `npm run dev`
5. Validate changes with `npm run lint` and `npm run build`.

See [Environment configuration](docs/ENVIRONMENT_CONFIG.md) for local, Preview, and Production setup and secret-handling rules. Never commit `.env.local`, production environment files, or real credentials.

See `docs/PROJECT_STRUCTURE.md` for the folder map and rules for generated/database files.

## Important conventions

- Routes are file-based under `src/routes/`.
- `src/routeTree.gen.ts` is generated by TanStack Router; do not edit it manually.
- Supabase schema changes belong in new, timestamped files under `supabase/migrations/`; do not rewrite applied migrations.
- `drizzle/migrations/` is a separate migration history. Do not move or merge it into Supabase migrations without a deliberate migration-history reconciliation.
- Never commit credentials, service-role keys, or production environment files.
